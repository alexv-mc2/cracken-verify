cracken-verify

Offline check of a crAcken Prove bundle. Everything runs in this page; nothing is sent anywhere unless you tick the block-header box. Same checks as the command-line tool in this repository.

What this checks

  1. Every file in the zip matches the SHA-256 listed in manifest.json; nothing is missing or unlisted.
  2. Every event in events.jsonl recomputes to its row_hash (crAcken org-event-log format v1) and links to the previous one, from seq 1 to the head.
  3. The RFC 6962 inclusion path in checkpoint.json leads from that head to the checkpoint root.
  4. The RFC 3161 token and the OpenTimestamps proof are over that root; their times say the root existed no later than then.

What you still trust: the TSA root certificate you chose (revocation is not checked offline), the Bitcoin block headers you supplied or fetched, and this page's code (MIT, source and build in the repository; compare the SHA-256 of this file with the published one). crAcken's own signature is shown but not needed.
